# Håpsbånd

Koselig og mobiltilpasset nettside for elevbedriften Håpsbånd.

## Om bedriften
Håpsbånd drives av Tino, Anbien, Mathea, Melissa, Falk og Liam.

## Viktig innhold
- Informasjon om Kreftforeningens arbeid med forskning, forebygging og støtte
- Armbånd med «FUCK CANCER» og positive ord som håp og styrke
- Ett armbånd koster 60 kr
- Kombopakke med to armbånd koster 100 kr
- 15 % av fortjenesten går til Kreftforeningen
- Bedriften prøver å støtte klassekassa samtidig som den bidrar i kampen mot kreft
- Varme blå, turkis og kremfarger inspirert av logoen

Åpne `index.html` i en nettleser for å vise nettsiden.
